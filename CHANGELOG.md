# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/), and this project adheres to
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-08-25

Первый публичный релиз.

### Сайты

- Мониторы трёх типов: HTTP(S), TCP-порт и срок TLS-сертификата. Ожидаемый код
  ответа, ключевое слово и стоп-слово в теле, метод запроса, базовая авторизация,
  свои заголовки, отдельные пороги «медленно» и «недоступен», повторы перед
  вердиктом.
- Проверка из нескольких точек: панель ходит к сайту напрямую и через заданные
  прокси. Если сайт виден не отовсюду — это отдельное состояние «доступен не из
  всех точек» со сводкой, а не «всё хорошо».
- История, инциденты и доступность за сутки, неделю и месяц.
- Домены, найденные на веб-серверах парка, панель предлагает поставить на
  мониторинг сама — искать непокрытый сайт руками не нужно.

### Серверы

- Агент без root: непривилегированный пользователь, только исходящие соединения,
  systemd-вотчдог и самовосстановление. Ставится одной командой из панели, снимается
  тоже одной.
- Метрики хоста: процессор с разбивкой по ядрам, память, диски и их температура,
  сеть, сокеты, conntrack, OOM, троттлинг, время работы.
- Docker через ограниченный прокси — просмотр контейнеров, перезапуск и логи без
  выдачи агенту root.
- Kubernetes (k0s/k3s/microk8s/kubeadm): узлы, поды и нагрузки, а из управления —
  только перезапуск деплоймента, удаление пода и логи, через выделенный
  ServiceAccount.
- Инвентарь СУБД и веб-серверов: базы и их размеры, домены из конфигураций
  nginx/Apache/Caddy, Ingress и Gateway API.
- Контроль часов: расхождение времени ноды с панелью видно до того, как оно
  сломает TOTP, TLS и корреляцию логов.

### Бэкапы

- Состояние restic-бэкапов парка: когда снимался, чем закончился, не устарел ли.
- Бэкап-сервер и клиентов можно развернуть прямо из панели — с append-only,
  приватными репозиториями и TLS.
- Сейф доступов с шифрованием на стороне браузера: панель хранит только
  шифротекст и прочитать его не может даже с полным доступом к базе.

### Алерты

- Telegram и webhook. Пороги, тексты и область действия каждого типа
  настраиваются; шумные состояния гасятся дебаунсом, всплеск — одним дайджестом.
- Заглушение по типам и по серверам, временная пауза, снуз до срока.

### Доступ

- Роли (администратор, редактор, наблюдатель), ограничение по разделам и группам
  серверов и сайтов, второй фактор (TOTP), журнал действий, ограничение попыток
  входа.
- Панель за Caddy с автоматическим сертификатом Let's Encrypt и списком
  разрешённых адресов; эндпоинты агентов открыты отдельно.

### Эксплуатация

- Установка одной командой на чистом сервере, включая Docker и TLS: домен не
  обязателен, по умолчанию берётся `<IP>.sslip.io`.
- Обновление образами из GHCR либо сборкой из исходников; миграции применяются
  сами, данные остаются на месте.
- Резервные копии конфигурации по расписанию и восстановление из файла.
- Самообновление агента по подписанному манифесту: приватный ключ хранится
  офлайн, и панель, даже захваченная, подделать релиз не может.
- Масштабирование на несколько воркеров с отдельным планировщиком.
