Features

Your whole infrastructure on one screen

What usually lives in three separate systems is gathered here into one and tied together: the monitor that went red and the machine behind it are two clicks apart, on the same timeline.

Sites, as your users see them

Status, keyword, response time, certificate and domain expiry. Checks also run from other regions, so the panel tells you right away when a site opens for you but is down for half the world.

Servers, from the inside

A single static binary reports CPU per core, memory, disks per mount, network, temperature, throttling, OOM kills and process tops. The connection is always outbound — the node's ports stay closed.

Everything running on the machine

Docker containers and Kubernetes pods, web servers with the domains they serve, databases with their sizes, RabbitMQ queues. The panel finds all of it and offers to put the discovered domains under monitoring.

Backups under watch

restic state for every node, repositories on your own server, whether the run fit its night window — and a vault of restore credentials that is encrypted right in your browser.

Alerts people keep reading

Telegram and webhook, your own text per alert type, thresholds that have to hold, snooze and per-signal mute. Routing follows roles — everyone gets what they are responsible for.

The panel watches itself too

An outdated agent, a probe location that stopped working, a drifting clock, a backup that ran late — all of it lands in "Action needed" with the command that fixes it.

Out of the box

Working where a configuration project usually begins

A classic monitoring stack is assembled: an exporter per concern, a scrape config, rules, alert routes and a dashboard for each thing you want to see. Kervax delivers the same results already wired together.

Prometheus remains the strongest tool for application metrics and ad-hoc PromQL — and lives happily alongside. Kervax covers the infrastructure: the host, the site, the certificate, the container, the backup.

Install

One command and the panel is ready

Run it on a fresh Linux server. It installs Docker, brings up Caddy with a Let's Encrypt certificate, generates the secrets and prints the panel's address together with the admin password.

$ curl -fsSL https://raw.githubusercontent.com/mihsergeev/Kervax/main/ops/quickstart.sh | sudo sh
Your own domain, optionally

Without one the panel comes up on <server-ip>.sslip.io — with a real certificate, on https from the start.

A server to watch

"Add server" shows a ready command. Run it on the node and the machine appears with all its metrics within seconds.

A site to watch

An address is enough. Scheme, certificate, domain and history are picked up from the very first check.

Need your own domain, an IP allow-list, an existing nginx in front, or a step-by-step walkthrough? It is all in the installation guide.

Security

Built to be trusted with your infrastructure

  • The agent only connects outwards. It listens on no port and runs no shell commands, and the panel keeps nothing but a SHA-256 of its token.
  • Roles are enforced in the API. An account limited to a group sees only its own objects — even when an id is requested directly.
  • Everything runs without root. The backend under its own user, the frontend on an unprivileged image, containers with no-new-privileges.
  • Sign-in is guarded. JWT plus TOTP second factor, attempt limits, an audit log; passwords from 12 characters, and a weak secret is refused outright.
  • Agent updates rest on an offline key. Signatures are made away from the server, so even a compromised panel cannot make agents run someone else's code.
